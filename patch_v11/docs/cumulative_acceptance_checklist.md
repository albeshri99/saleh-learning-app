# سجل الملاحظات التراكمي — الإصدار القادم

هذا الملف بوابة إلزامية قبل بناء أي IPA جديد. لا تُعد الملاحظة ملغاة عند ورود
ملاحظة أحدث، ولا يبدأ البناء ما دام أي بند مطلوب غير متحقق.

## واجهة الدرس

- [x] أزرار الإجراءات (`هيا نبدأ`، `تذكرتها`، `مرة أخرى`، وما يماثلها) صغيرة، كاملة بلا قص، وفي موضع سفلي ثابت.
- [x] لا يظهر تمرير رأسي في شاشة الآيفون الأفقية، وجميع العناصر الأساسية ظاهرة.
- [x] ترتيب العربية من اليمين إلى اليسار.
- [x] زر `تذكرتها` يطابق حجم وموضع ولون زر `السؤال التالي` البنفسجي.
- [x] لا يظهر شريط تقدم طويل؛ يعرض الرأس أيقونة درس صغيرة ورقم الخطوة.

## حرف الثاء والكتابة

- [x] شكل الثاء في الشرح والدليل والتتبع والنتيجة المكتملة متطابق.
- [x] جسم الثاء قريب من شكل الخط في المرجع المعتمد وليس قوسًا نصف دائري.
- [x] النقاط الثلاث جزء من التتبع وتكتمل قبل نجاح النشاط.
- [x] النقاط الثلاث واضحة فوق جسم الثاء بترتيب مثلثي مطابق للدليل.
- [x] الكتابة الحرة تعرض سبورة قابلة للرسم فعلًا.
- [x] لا يمكن تجاوز الكتابة الحرة بزر `التالي` قبل وجود حبر.
- [x] لا ينتقل النشاط إلا بعد كتابة الطفل ثم ضغط زر الإنهاء.

## أيقونة التطبيق

- [x] المصدر المعتمد هو `assets/images/app_icon_source.png`.
- [x] جميع مقاسات AppIcon في iOS مولدة من المصدر المعتمد.
- [x] جميع mipmap في Android/Huawei مولدة من المصدر نفسه.

## الشخصية والمشاهد

- [x] حالة صالح تتبع المشهد وتبقى في Loop حتى الانتقال.
- [x] لا تظهر كروما أو خلفية أو طبقات شخصية مكررة.
- [x] صالح واقف على الأرض ولا يبدو طائرًا.

## بوابة البناء

- [x] `flutter analyze` بلا أخطاء.
- [x] جميع الاختبارات ناجحة.
- [x] مراجعة بصرية للشاشات المعدلة على نسبة آيفون أفقية.
- [x] بناء IPA جديد باسم إصدار جديد، وعدم تثبيت إصدار قديم.
